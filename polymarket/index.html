Fair values use a zero-drift lognormal diffusion on the challenger/leader market-cap ratio: P(flip) = Φ(ln(capchal/caplead) / σ√T), T in trading days (1 / 22 / 107), base σrel = 2%/day with a 3%/day final-session case for July.
